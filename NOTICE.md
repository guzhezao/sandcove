# Sources and modification notice

SANDCOVE is a modified version of [Sandboard](https://github.com/scottstts/Sandboard), by GitHub user **scottstts**. The upstream base used for this work was commit `489cb01e81b11ba575887f7c76760498eb41aaa8`. The upstream project and this derivative are distributed under **GPL-3.0-only**. See `LICENSE` for the complete license text.

## Changes

Modified work: **沙滩小筑 / SANDCOVE**, maintained by **guzhezao**.

- **2026-10-21–2026-10-22, through V19.1:** added digging, building and pouring tools; a GPU shallow-water solver, water rendering and terrain erosion; castle molds; tide and tsunami behavior; camera and Chinese interface changes; beach characters, scenery and audio interaction; regression tests. These changes affect `src/`, `tests/`, application metadata and supporting project files.
- **2026-10-28:** prepared this standalone showcase repository, rewrote the README, added the V19.1 screenshot and source notices, renamed package metadata, and linked the in-game source page to this repository. Updated development dependency lockfile patches (including Vite 8.3.5 and Vitest 5.0.5) to resolve the five findings reported by npm audit. Game logic was copied without changes from V19.1.

The work was directed and revised over multiple rounds using MiniMax M3.1 Flash and Codex. It is not an unattended single-generation result.

## Assets

The ambient audio (`public/scene_assets/beach.mp3`, `wave.mp3`), palm model (`coconut_tree.glb`), logo and social image were inherited from the Sandboard source tree and remain covered by its repository license and notices. Sand drawing, pouring, mold placement and other synthesized effects are generated by the application code. `docs/images/sandcove-v19.1.jpg` is a screenshot of this modified game.

No separate asset credit file was present in the upstream checkout. This repository retains the upstream license rather than assigning a new permissive license to those assets.

Steam's **Sandcastle** was a gameplay reference only. No Sandcastle code or game assets are included, and this project is not affiliated with or endorsed by its creators.
